# KnowYourGov

Independent, nonpartisan civic education for Nigeria. Built with Next.js, TypeScript, CSS Modules and browser-local preferences.

Use Node.js 20.9 or newer. Run `npm ci`, then `npm run dev` and visit http://localhost:3000. Run `npm run build` to generate the static site in `out/`.

Location data: [Nigeria Administrative Divisions](https://github.com/open-admin-data/nigeria-administrative-divisions), Open Admin Data, CC BY 4.0, downloaded 16 November 2026; reduced to identifiers and names. This third-party dataset should be cross-checked against an authoritative government list before production.

Local government election authority websites require state-by-state verification. Where none is verified the site explicitly says so instead of guessing a URL. Election procedures and legal descriptions require periodic expert review.
